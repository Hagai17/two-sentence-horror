Entry for the make.fun bounty
[Two-Sentence Horror](https://make.fun/bounties/u-suroto-two-sentence-horror-acea9253):
the scariest horror story that fits in exactly two sentences.

## The entry

> My phone transcribes my mother's voicemails, and lately the transcripts include a second voice — one I can't hear in the audio — answering her. Last night's transcript ended with that voice saying: 'He reads these, so stop warning him.'

## Run it

```sh
python3 main.py
```

The program prints the entry to stdout and writes it, byte for byte, to
`/output/entry.txt`, where the make.fun program/v1 harness reads it. It
first checks the entry against the competition gate: 1–400 characters,
not only white space, exactly two sentences.

## How it was chosen

Twelve candidate stories were drafted and duel-scored pairwise against
the kit's published judge criteria — genuinely frightening first, then
the second-sentence turn that makes the first worse on a second read,
implied rather than explained horror, precise concrete prose, and
originality. The full field and the duel notes are in
[candidates.md](candidates.md).
